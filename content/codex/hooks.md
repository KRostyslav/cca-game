## Навіщо

Hook — це **код, який харнес виконує детерміновано** на кожну подію. Інструкція в CLAUDE.md — текст, який модель може врахувати або ні.

Якщо щось має відбуватися **завжди** — це робота для hook.

## Основні події

| Подія | Момент | Типове застосування |
|---|---|---|
| `PreToolUse` | До виконання інструмента | Заборонити дію, перевірити аргументи |
| `PostToolUse` | Після виконання | Форматування, лінт, збірка |
| `UserPromptSubmit` | При надсиланні запиту | Додати контекст, валідація вводу |
| `SessionStart` / `SessionEnd` | Межі сесії | Підготовка й прибирання |
| `PreCompact` | Перед компакцією | Зберегти стан назовні |
| `Stop` / `SubagentStop` | Завершення ходу | Сповіщення, звіт |

Блокувати можна лише те, що ще **не сталося** — тобто в `PreToolUse`.

## Коди виходу

| Код | Значення |
|---|---|
| `0` | Успіх |
| `2` | **Дію заблоковано**, stderr передається Claude як пояснення |
| інший | Неблокуюча помилка, виконання триває |

Код 2 — це і заборона, і зворотний зв'язок: модель дізнається причину і може обрати інший шлях замість сліпого повтору.

## Приклад

```json
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Edit|Write",
        "hooks": [{ "type": "command", "command": "ruff format \"$CLAUDE_FILE_PATH\"" }]
      }
    ]
  }
}
```

| Задача | Куди |
|---|---|

| Логувати команди для аудиту | Hook |
| Пояснити архітектуру проєкту | CLAUDE.md |
| Задати домовленості щодо стилю | CLAUDE.md |
