## Що робить систему агентною

Workflow — це шлях, який задав розробник. Агент — це **цикл, у якому модель сама обирає наступну дію** на підставі результатів попередніх. Передача контролю над потоком керування моделі — і є визначальна ознака.

## Канонічний цикл

1. **Gather context** — зібрати те, що потрібно для наступного рішення.
2. **Take action** — викликати інструмент.
3. **Verify work** — перевірити результат дії.
4. **Repeat** — або завершити.

Крок перевірки пропускають найчастіше — і саме без нього агент накопичує помилки, не помічаючи їх.

## Механіка на рівні API

Messages API не має стану: історію надсилають повністю щоразу.

```ts
const messages: Anthropic.MessageParam[] = [{ role: "user", content: task }];

while (true) {
  const res = await client.messages.create({
    model: "claude-opus-5",
    max_tokens: 16000,
    tools,
    messages,
  });

  messages.push({ role: "assistant", content: res.content });
  if (res.stop_reason !== "tool_use") break;

  // Усі tool_result — в ОДНОМУ user-повідомленні
  const results = await Promise.all(
    res.content
      .filter((b) => b.type === "tool_use")
      .map(async (b) => ({
        type: "tool_result" as const,
        tool_use_id: b.id,
        content: await runTool(b.name, b.input),
      })),
  );
  messages.push({ role: "user", content: results });
}
```

## Правила, які часто порушують

| Правило | Чому |
|---|---|
| `tool_result` повертають у повідомленні з роллю `user` | Це відповідь програми, а не продовження репліки моделі |
| Усі паралельні результати — в одному повідомленні | Розбиття на кілька тихо відучує модель від паралельних викликів |
| Кожному `tool_use` — свій `tool_result` із тим самим `tool_use_id` | Пропущений блок = помилка структури запиту |
| Помилку повертають як `tool_result` з `is_error: true` | Модель має бачити збій, щоб виправитися |

## Умови зупинки

Обов'язкові три:

- `stop_reason === "end_turn"` — щасливий шлях;
- ліміт ітерацій — захист від зациклення;
- бюджет токенів або часу — захист від рахунку.

Помилка інструмента **не** є умовою зупинки: це дані для моделі.

## Діагностика зациклення

Повторювані однакові виклики майже завжди означають, що інструмент не дає сигналу про прогрес. Порожній масив без пояснення читається як «спробуй ще раз інакше». Лікування — у дизайні інструмента, а не в підвищенні лімітів. Див. [[tool-schemas-errors]].
